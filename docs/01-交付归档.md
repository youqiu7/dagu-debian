## 2. 关键修复（按重要性）

### 2.1 音频：ASP 绕过 DSP（最大突破）

```
问题  音量拉满仍小、音质糊、没高低频
根因  CS35L41 的 DSP 加载 Protection 算法（动态压缩），且 EQ 提升在下游被压回
修复  PCM Source: DSP → ASP（四路），音频串口直通，跳过 DSP
效果  动态范围恢复，用户实测"好听多了"
```

**持久化**：UCM `HiFi.conf` 的四条 cset + `alsactl store`

### 2.2 音量：改 UCM 源文件而非运行时

```
问题  手动拉满 913/20，放歌又回 817/18
根因  UCM 每次路由执行 cset，重置为原厂默认值
修复  直接改 /usr/share/alsa/ucm2/Xiaomi-dagu/HiFi.conf
```

### 2.3 OSK：必须在 shell 启动前设置

```
问题  锁屏/搜索框都不弹键盘
根因  gnome-shell 启动时读一次 screen-keyboard-enabled，读到 false 就销毁 KeyContainer
      （日志：Object .Gjs_ui_keyboard_KeyContainer has been already disposed）
修复  1. youqi 的 gsettings 设 true
      2. GDM 的 /etc/dconf/db/gdm.d/00-osk + /etc/dconf/profile/gdm
      3. 必须重启（运行中改 gsettings 无效）
```

**Electron 无解**：Chromium 的 wayland text-input 只做 IME，不实现 OSK 的 enable 请求。
VutronMusic/YesPlayMusic 等都无法弹键盘。

### 2.4 WiFi 固件：rootfs 必须有一份

```
问题  网卡 reset/resume 后 wlp1s0 unavailable
根因  ath11k 固件只在 vendor_boot 的 initramfs 里，运行时去 rootfs 找 → -2 ENOENT
修复  从 boot-dagu.img 的 initramfs 提取 3 个文件到 /lib/firmware/ath11k/QCA6390/hw2.0/
```

### 2.5 时间：无 RTC 必须 fake-hwclock

```
问题  apt 反复 SSL certificate verify failed
根因  无 RTC 电池 + 无 fake-hwclock，每次开机时间从内核编译日期起算
修复  fake-hwclock + systemd-timesyncd + 国内 NTP + date -s 拉正
```

### 2.6 rootfs 与 boot 链

```
2026-10-21 事故  解压自编内核模块到 /lib/modules 导致 rootfs 损坏
处置             放弃修复，用 rootfs-1.5g.img 重建
正式版 boot      ee2d066be9c544b123ceefb4b682d87e
正式版 vendor_boot 1e6dfedc0cfa30fff6a69a4d03803523
```
