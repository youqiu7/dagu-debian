## 2. 本次补上的两个遗漏

### 2.1 ath11k 固件（之前只手工补在设备上）

```
firmware/ath11k-firmware.tar.gz    2.0 MB
  lib/firmware/ath11k/QCA6390/hw2.0/board.bin
  lib/firmware/ath11k/QCA6390/hw2.0/m3.bin
  lib/firmware/ath11k/QCA6390/hw2.0/amss.bin
```

脚本 §3 解压并校验（至少 3 个文件，否则 die）。

**为什么必须有**：作者只把固件放进 vendor_boot 的 initramfs，那是一次性的。
网卡任何 reset/suspend 恢复都会去 rootfs 找固件，找不到就 `-2 ENOENT`，
`wlp1s0` 变 unavailable —— 这次就是这么掉线的。

### 2.2 时间同步（之前只手工在设备上设过）

脚本新增 **§0**，位置在所有 apt 之前：

```
1. date +%Y < 2026 视为时间异常 → 提示输入正确时间
2. ln -sf Asia/Shanghai /etc/localtime
3. apt 装 util-linux-extra / fake-hwclock / systemd-timesyncd
4. 写 /etc/systemd/timesyncd.conf.d/99-cn.conf（阿里/腾讯 NTP）
5. systemctl enable --now systemd-timesyncd
6. fake-hwclock save
```

**为什么必须最先做**：时间不对时 apt 报 `SSL certificate verify failed`，
后面每一个 `apt-get install` 都会失败 —— 整台设备装不完。

## 3. 不在安装包里（需要额外处理）

| 项目 | 原因 | 怎么办 |

| **WPS Office** | 789 MB deb 没放进包（体积 + 版权） | 从 WPS 365 官网下 ARM64 deb，放到 `/root/wps365_arm64.deb`，脚本 §7 会自动装 |

## 4. 使用顺序（下一台设备）

```
1. fastboot flash boot_b        images/boot-dagu.img
2. fastboot flash vendor_boot_b images/vendor_boot-dagu.img
3. fastboot flash userdata      images/rootfs-1.5g.img
4. fastboot set_active b && fastboot continue
5. 串口/SSH 登录 root
6. bash install/setup-system.sh
   ├── §0 提示输入当前时间（关键，否则 apt 全挂）
   ├── §4 提示输入 WiFi SSID/密码
   ├── §5 装 GNOME 约 10-30 分钟
   ├── §7 若放了 wps365_arm64.deb 会自动装
   └── §8 自动验证
7. 重启 → 自动登录桌面，音频/OSK/EQ 全部就绪
```

## 5. 验证清单（装完后逐项确认）

```bash
# 时间
date; systemctl is-active systemd-timesyncd          # 时间正确 + active

# WiFi 固件
ls /lib/firmware/ath11k/QCA6390/hw2.0/               # 3 个文件
ip -br a | grep wlp1s0                                # UP + IP

# 音频
amixer -c0 cget name="TL PCM Source" | grep values    # values=0 (ASP)
amixer -c0 cget name="TL Digital PCM Volume" | grep values  # 913
amixer -c0 cget name="TL Amp Gain ZC Switch" | grep values  # on
su - youqi -c "XDG_RUNTIME_DIR=/run/user/1001 wpctl status" | grep Speakers

# 虚拟键盘
su - youqi -c "XDG_RUNTIME_DIR=/run/user/1001 DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1001/bus gsettings get org.gnome.desktop.a11y.applications screen-keyboard-enabled"  # true

# 服务
systemctl is-active gdm3 dagu-audio-up NetworkManager
su - youqi -c "XDG_RUNTIME_DIR=/run/user/1001 systemctl --user is-active easyeffects"
```
